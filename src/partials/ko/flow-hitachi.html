  2. 02제어·촬영
    • 한 일
      비개발자 연구원이 개발 환경 없이 직접 촬영하고 데이터셋을 만드는 PyQt GUI를 만들어 PyInstaller 실행 파일로 배포. 모든 단계를 GUI 하나에서 실행합니다.
      기술
      • PyQt
      • PyInstaller

      기술
      • Python
      • PySpin
      • Spinnaker SDK
