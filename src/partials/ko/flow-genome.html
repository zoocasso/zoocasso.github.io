1. 01입력
    • 입력
      시퀀싱 원본 데이터(FASTQ). 변이 호출 파이프라인의 입력입니다.
    • 입력
      고객이 올리는 VCF 파일 또는 유전자 칩(array) 결과 파일.
    • 데이터
      dbSNP(GRCh37, GRCh38) 237 GB, 1000 Genomes 770 GB, GWAS Catalog, UniProt. 크기는 원본 기준입니다.
  2. 02처리
    • 한 일
      FASTQ → BWA → samtools → Picard → GATK → VCF 파이프라인 구현.
      다른 주체
      파이프라인 알고리즘은 회사에서 팀장과 함께 설계했습니다.
      기술
      • BWA
      • samtools
      • Picard
      • GATK
    • 한 일
      고객 VCF·칩(array) 입력을 PyVCF로 읽어 주석에 쓰는 입력 테이블로 정리. 칩 입력은 rsID로 dbSNP에서 위치 키를 찾습니다.
      기술
      • PyVCF
      • Python
  3. 03저장
    • 한 일
      dbSNP(237 GB), 1000 Genomes(770 GB), GWAS Catalog, UniProt를 MySQL로 구축. 염색체 단위로 파일을 나누고(sed, split) pandas 청크와 SQLAlchemy로 나눠 적재.
      기술
      • MySQL
      • pandas
      • SQLAlchemy
      • sed · split
  4. 04주석
    • 한 일
      dbSNP·1000 Genomes는 염색체·위치·REF·ALT 키로, GWAS Catalog는 rsID와 위험 대립유전자로, UniProt은 변이 ID와 대립유전자로 붙이는 4단계 SQL 조인. GWAS 오즈비·베타값 기반 규칙형 위험점수, 1000 Genomes 26개 집단 대립유전자 빈도 비교, 질환별 의약품·한약재 정보(MedlinePlus, MeSH, ATC, PharmDB-K, OASIS) 연결.
      참고
      질환과 한약을 잇는 LDA·1D-CNN 모델은 프로토타입 실험에 그쳤습니다.
      기술
      • SQL
      • MySQL
      • Python
  5. 05서빙
    • 다른 주체
      화면 디자인은 캐나다 바이오 연구소의 디자이너가 맡았습니다.
      한 일
      디자이너와 요구사항을 조율하고, 한국과 캐나다 팀 사이의 기술 소통을 맡았습니다.
    • 한 일
      리포트를 FastAPI JSON API로 제공하고 사용자 화면(프런트엔드)도 개발. 2023년 9월 웹 화면을 떼어 내 프런트엔드가 쓰는 JSON API로 정리.
      기술
      • FastAPI
      • JSON API
    • 한 일
      Korea IDC의 Ubuntu 운영서버에 Harbor 사설 레지스트리를 직접 구축(인증서, 도메인, Let's Encrypt)하고 Docker 이미지로 배포. 운영서버는 내부 IP로만 접근하게 두었습니다.
      기술
      • Docker
      • Harbor
      • Ubuntu
      • Let's Encrypt
