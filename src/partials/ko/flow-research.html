ICMV 2026RIM · 각도 정보를 공간 해상도로
  1. 데이터
    Stanford Lytro 라이트필드 7개 장면으로 평가했습니다. 렌즈 하나가 만드는 요소 영상은 몇 픽셀 크기로 작습니다.
  2. 방법
    (렌즈 번호, 렌즈 안 픽셀 위치)를 맞바꾸는 일대일 재배열(Ray-based Inverse Mapping). 텔레센트릭 촬영과 정사영 재촬영 조건에서 보간이 없어 양자화 오차가 0입니다.
    발표
    ICMV 2026, 부다페스트 · 최우수 포스터상
    자세히
    RIM·iRIM 페이지
  3. 방법
    재배열한 시점 영상을 컴퓨터 집적영상 재구성(CIIR)의 앞 단계로 쓰고, 요소 영상을 그대로 쓴 경우와 비교했습니다.
  4. 결과
    Lytro 7개 장면에서 {{f:rim_psnr}}, {{f:rim_ssim}}, 사전학습 YOLO 검출 {{f:rim_map}}.
ITC-CSCC 2025 · 2026원점 최적화 VCR
  1. 데이터
    9×9 요소 영상과 카메라 파라미터, 재생할 깊이.
  2. 방법
    양자화 오차를 줄이는 원점을 찾으려고 재생을 반복하던 탐색을, 카메라 파라미터만으로 하는 계산으로 바꿨습니다. 논문 실험에서 반복 탐색과 같은 원점·SSIM을 얻었습니다.
    발표
    ITC-CSCC 2025(서울, 포스터) · ITC-CSCC 2026(방콕, 구두)
  3. 결과
    9×9 요소 영상 기준, 원점을 고르기 위한 재구성이 81번에서 1번으로 줄었습니다.
    기술
    • Python
    • NumPy
    • CuPy
  4. 결과
    CPU 0.31초(논문 측정), GPU(CuPy, RTX 3090) {{f:origin_gpu}}. 반복 탐색의 25.45초는 1회 0.3142초 × 81로 낸 추정치입니다.
    코드
    origin-point-optimization-vcr
ICCAS 2026iRIM · 가상 렌즈 배열
  1. 데이터
    여러 위치에서 렌더링한 시점 영상.
  2. 방법
    RIM이 일대일 대응이라 거꾸로도 쓸 수 있습니다. 다시점 영상에서 원하는 가상 렌즈 배열의 요소 영상을 합성합니다.
    발표
    ICCAS 2026, 삿포로 · 포스터 발표
  3. 결과
    24인치 FHD 패널에 맞춘 6×6 구성(렌즈 320×180개). 모든 시점 영상의 유효 영역이 100%로, 렌즈 배열 카메라 시뮬레이션의 모서리 시점(6.7%)과 비교됩니다.
