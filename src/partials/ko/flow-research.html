ICMV 2026RIM · 각도 정보를 공간 해상도로
  1. 데이터
    Stanford Lytro 라이트필드의 실제 촬영 영상으로 평가했습니다. 렌즈 하나가 만드는 요소 영상은 몇 픽셀 크기로 작습니다.
  2. 방법
    (렌즈 번호, 렌즈 안 픽셀 위치)를 맞바꾸는 일대일 재배열(Ray-based Inverse Mapping). 텔레센트릭 촬영과 정사영 재촬영 조건에서 보간이 없어 양자화 오차가 없습니다.
    발표
    ICMV 2026, 부다페스트 · 최우수 포스터상
    자세히
    RIM·iRIM 페이지
  3. 방법
    재배열한 시점 영상을 컴퓨터 집적영상 재구성(CIIR)의 앞 단계로 쓰고, 요소 영상을 그대로 쓴 경우와 비교했습니다.
  4. 결과
    실제 Lytro 영상에서 화질과 물체 검출 성능을 함께 개선.
ITC-CSCC 2025 · 2026원점 최적화 VCR
  1. 데이터
    요소 영상과 카메라 파라미터, 재생할 깊이.
  2. 방법
    양자화 오차를 줄이는 원점을 찾으려고 재생을 반복하던 탐색을, 카메라 파라미터만으로 하는 계산으로 바꿨습니다. 논문 실험에서 반복 탐색과 같은 원점·화질을 얻었습니다.
    발표
    ITC-CSCC 2025(서울, 포스터) · ITC-CSCC 2026(방콕, 구두)
  3. 결과
    계산한 원점으로 바로 재구성해, 원점을 고르려고 재구성을 되풀이하지 않습니다.
    기술
    • Python
    • NumPy
    • CuPy
  4. 결과
    반복 탐색을 직접 계산으로 바꾸고 GPU(CuPy)로도 구현. 논문 실험에서 같은 화질을 유지하면서 처리 시간을 크게 단축.
    코드
    origin-point-optimization-vcr
ICCAS 2026iRIM · 가상 렌즈 배열
  1. 데이터
    여러 위치에서 렌더링한 시점 영상.
  2. 방법
    RIM이 일대일 대응이라 거꾸로도 쓸 수 있습니다. 다시점 영상에서 원하는 가상 렌즈 배열의 요소 영상을 합성합니다.
    발표
    ICCAS 2026, 삿포로 · 포스터 발표
  3. 결과
    디스플레이 패널에 맞춘 구성으로 합성. 모든 시점 영상의 전 영역이 유효해, 모서리 시점에서 유효 영역이 크게 줄어드는 렌즈 배열 카메라 시뮬레이션과 비교됩니다.
