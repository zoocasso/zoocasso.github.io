1. 01クライアント
    • 他の担当
      ゲームクライアントは、チームのもう1人が開発しました。
      アクセス
      アップデート時に集中。
      報告
      譜面ごとのプレイ回数をサーバーに送ります。
  2. 02エッジ
    • 担当内容
      サーバーの前段にCloudflareのプロキシとWAFを構成。認証なしで届く報告の濫用を、前段で防ぎます。
      技術
      • Cloudflare
      • WAF
  3. 03APIサーバー
    • 担当内容
      EC2のDockerコンテナで、FastAPIのプレイログ収集APIを運用。公開版では、コネクションプールの枯渇、再送による重複保存、入力の検証に対処しています。
      技術
      • FastAPI
      • Docker
      • AWS EC2
  4. 04保存
    • 担当内容
      プレイ報告をRDSのMySQLに保存。公開版では曲名を一文字ずつそのまま比較し、大文字・小文字やひらがな・カタカナだけが違う曲がまとめられないようにしました。
      技術
      • MySQL
      • AWS RDS
