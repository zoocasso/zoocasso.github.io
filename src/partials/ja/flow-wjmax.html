1. 01クライアント
    • 他の担当
      ゲームクライアントは、チームのもう1人が開発しました。
      規模
      平均同時接続{{f:wjmax_avg}}、アップデート時は最大{{f:wjmax_peak}}。
      報告
      曲ごとに、8つの譜面のプレイ回数をサーバーに送ります。
  2. 02エッジ
    • 担当内容
      サーバーの前段にCloudflareのプロキシとWAFを構成。認証なしで届く報告の濫用を、前段で防ぎます。
      技術
      • Cloudflare
      • WAF
  3. 03APIサーバー
    • 担当内容
      EC2のDockerコンテナで、FastAPIのプレイログ収集APIを運用。2026年10月の書き直し版では、コネクションプールの枯渇、再送による重複保存、入力の検証に対処しています。
      技術
      • FastAPI
      • Docker
      • AWS EC2
  4. 04保存
    • 担当内容
      プレイ報告をRDSのMySQLに保存。書き直し版では、曲名をバイト単位でそのまま比較する照合順序（utf8mb4_0900_bin）を使います。
      技術
      • MySQL
      • AWS RDS
