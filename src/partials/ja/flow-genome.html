1. 01入力
    • 入力
      シーケンシングの生データ（FASTQ）。変異検出パイプラインの入力です。
    • 入力
      顧客がアップロードするVCFファイル、または遺伝子チップ（アレイ）の結果ファイル。
    • データ
      dbSNP（GRCh37、GRCh38）237 GB、1000 Genomes 770 GB、GWAS Catalog、UniProt。サイズは元データの値です。
  2. 02処理
    • 担当内容
      FASTQ → BWA → samtools → Picard → GATK → VCFのパイプラインを実装。
      他の担当
      パイプラインのアルゴリズムは、社内でチームリーダーと共同で設計しました。
      技術
      • BWA
      • samtools
      • Picard
      • GATK
    • 担当内容
      顧客のVCF・チップ（アレイ）の入力をPyVCFで読み込み、アノテーションに使う入力テーブルに整理。チップの入力は、rsIDを使ってdbSNPから位置キーを引きます。
      技術
      • PyVCF
      • Python
  3. 03保存
    • 担当内容
      dbSNP（237 GB）、1000 Genomes（770 GB）、GWAS Catalog、UniProtをMySQLに構築。染色体単位でファイルを分割し（sed、split）、pandasのチャンクとSQLAlchemyで少しずつ蓄積。
      技術
      • MySQL
      • pandas
      • SQLAlchemy
      • sed · split
  4. 04アノテーション
    • 担当内容
      dbSNP・1000 Genomesは染色体・位置・REF・ALTのキーで、GWAS CatalogはrsIDとリスクアレルで、UniProtは変異IDとアレルで結合する4段階のSQL結合。GWASのオッズ比・β値に基づくルールベースのリスクスコア、1000 Genomesの26集団のアレル頻度の比較、疾患ごとの医薬品・韓方生薬の情報（MedlinePlus、MeSH、ATC、PharmDB-K、OASIS）とのひも付け。
      補足
      疾患と韓方薬を結ぶLDA・1D-CNNのモデルは、プロトタイプの実験にとどまりました。
      技術
      • SQL
      • MySQL
      • Python
  5. 05提供
    • 他の担当
      画面デザインは、カナダのバイオ研究所のデザイナーが担当しました。
      担当内容
      デザイナーと要件を調整し、韓国とカナダのチーム間の技術的なやり取りを担当しました。
    • 担当内容
      レポートをFastAPIのJSON APIで提供し、利用者向けの画面（フロントエンド）も開発。2023年9月にWeb画面を切り離し、フロントエンドが使うJSON APIとして整理。
      技術
      • FastAPI
      • JSON API
    • 担当内容
      Korea IDCのUbuntu本番サーバーにHarborのプライベートレジストリを自分で構築し（証明書、ドメイン、Let's Encrypt）、Dockerイメージでデプロイ。本番サーバーには内部IPからのみアクセスできるようにしました。
      技術
      • Docker
      • Harbor
      • Ubuntu
      • Let's Encrypt
