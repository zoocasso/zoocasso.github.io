1. 01現場
    • 他の担当
      オランダの現地ラボのハードウェア構築は、設計を引き継いだ研究室の後輩が担当しました。
    • 機材
      産業用マシンビジョンカメラ複数台。Spinnaker SDK（PySpin）で制御します。
    • 他の担当
      サンプルの準備と基準判定（reference label）は、プロジェクトパートナーの研究者が担当しました。
      補足
      対象と計測項目は受託研究の機密のため、記載していません。
  2. 02制御・撮影
    • 担当内容
      開発者ではない研究員が、開発環境なしで自分で撮影し、データセットを作れるPyQtのGUIを作り、PyInstallerの実行ファイルとして配布。すべての段階を一つのGUIから実行します。
      技術
      • PyQt
      • PyInstaller
    • 担当内容
      マシンビジョンカメラ複数台を制御し、撮影条件をそろえて保存するモジュールを一から作成。
      技術
      • Python
      • PySpin
      • Spinnaker SDK
  3. 03計測・解析
    • 担当内容
      撮影結果から値を取り出して解析するプログラム。現地ではこのプログラムで、AI学習用のデータを作りました。
      技術
      • Python
  4. 04前処理
    • 担当内容
      撮影画像を整形し、学習に適した形に整理。既存コードと同じ入力で数値が一致するかを比べながら、段階ごとに置き換えました。
      技術
      • Python
  5. 05出力
    • 内容
      サンプル画像と基準判定（reference label）からなる、AI学習用のデータセット。
      補足
      研究テーマと計測対象は受託研究の機密のため、公開していません。
