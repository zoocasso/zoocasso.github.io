ICMV 2026RIM · angular samples into spatial resolution
  1. Data
    Evaluated on 7 Stanford Lytro light field scenes. The elemental image each lens forms is only a few pixels wide.
  2. Method
    A one-to-one rearrangement that swaps (lens index, pixel position under the lens) (Ray-based Inverse Mapping). Under telecentric capture and orthographic recapture there is no interpolation, so the quantization error is zero.
    Presented
    ICMV 2026, Budapest · Best Poster Award
    More
    RIM and iRIM page
  3. Method
    The rearranged views are used as the first stage of computational integral imaging reconstruction (CIIR) and compared with using the elemental images as they are.
  4. Result
    On the 7 Lytro scenes: {{f:rim_psnr}}, {{f:rim_ssim}}, and pretrained YOLO detection {{f:rim_map}}.
ITC-CSCC 2025 · 2026Origin point optimization for VCR
  1. Data
    9×9 elemental images, the camera parameters and the depth to reconstruct.
  2. Method
    The search that reconstructed again and again to find the origin with the least quantization error became a calculation from the camera parameters alone. In the paper's experiments it gave the same origin and SSIM as the iterative search.
    Presented
    ITC-CSCC 2025 (Seoul, poster) · ITC-CSCC 2026 (Bangkok, oral)
  3. Result
    For 9×9 elemental images, the reconstructions needed to choose the origin dropped from 81 to 1.
    Stack
    • Python
    • NumPy
    • CuPy
  4. Result
    CPU 0.31 s (measured in the paper), GPU (CuPy, RTX 3090) {{f:origin_gpu}}. The 25.45 s of the iterative search is an estimate, 0.3142 s per run × 81.

ICCAS 2026iRIM · virtual lens arrays
  1. Data
    Views rendered from several positions.
  2. Method
    Because RIM is one to one, it also runs backwards: iRIM synthesizes the elemental image of the virtual lens array you want from multi-view images.
    Presented
    ICCAS 2026, Sapporo · poster
  3. Result
    A 6×6 configuration matched to a 24-inch FHD panel (320×180 lenses). Every view has 100% effective coverage, against 6.7% for the corner views of a simulated lens array camera.
