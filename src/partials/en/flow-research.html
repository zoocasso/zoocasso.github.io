ICMV 2026RIM · angular samples into spatial resolution
  1. Data
    Evaluated on real images from the Stanford Lytro light field data. The elemental image each lens forms is only a few pixels wide.
  2. Method
    A one-to-one rearrangement that swaps (lens index, pixel position under the lens) (Ray-based Inverse Mapping). Under telecentric capture and orthographic recapture there is no interpolation, so the quantization error is zero.
    Presented
    ICMV 2026, Budapest · Best Poster Award
    More
    RIM and iRIM page
  3. Method
    The rearranged views are used as the first stage of computational integral imaging reconstruction (CIIR) and compared with using the elemental images as they are.
  4. Result
    Improved both image quality and object detection on real Lytro images.
ITC-CSCC 2025 · 2026Origin point optimization for VCR
  1. Data
    Elemental images, the camera parameters and the depth to reconstruct.
  2. Method
    The search that reconstructed again and again to find the origin with the least quantization error became a calculation from the camera parameters alone. In the paper's experiments it gave the same origin and image quality as the iterative search.
    Presented
    ITC-CSCC 2025 (Seoul, poster) · ITC-CSCC 2026 (Bangkok, oral)
  3. Result
    Reconstructs straight from the calculated origin, with no repeated runs to choose it.
    Stack
    • Python
    • NumPy
    • CuPy
  4. Result
    Replaced the iterative search with a direct calculation and a GPU (CuPy) implementation, cutting processing time sharply with the same image quality in the paper's experiments.

ICCAS 2026iRIM · virtual lens arrays
  1. Data
    Views rendered from several positions.
  2. Method
    Because RIM is one to one, it also runs backwards: iRIM synthesizes the elemental image of the virtual lens array you want from multi-view images.
    Presented
    ICCAS 2026, Sapporo · poster
  3. Result
    A configuration matched to a display panel. Every view has full effective coverage, whereas a simulated lens array camera loses most of it in the corner views.
