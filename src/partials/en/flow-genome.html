1. 01Input
    • Input
      Raw sequencing data (FASTQ), the input to the variant-calling pipeline.
    • Input
      A VCF file or a genotyping-array (chip) result file uploaded by the customer.
    • Data
      dbSNP (GRCh37, GRCh38) 237 GB, 1000 Genomes 770 GB, the GWAS Catalog and UniProt. Sizes are for the source files.

  3. 03Storage
    • What I did
      Built dbSNP (237 GB), 1000 Genomes (770 GB), the GWAS Catalog and UniProt into MySQL. Split the files by chromosome (sed, split) and loaded them in pandas chunks through SQLAlchemy.
      Stack
      • MySQL
      • pandas
      • SQLAlchemy
      • sed · split
  4. 04Annotation
    • What I did
      A four-stage SQL join: dbSNP and 1000 Genomes on a key of chromosome, position, REF and ALT, the GWAS Catalog on rsID and risk allele, and UniProt on variant ID and allele. A rule-based risk score from GWAS odds ratios and betas, allele frequencies compared across the 26 populations of 1000 Genomes, and drug and herbal-medicine information per disease (MedlinePlus, MeSH, ATC, PharmDB-K, OASIS).
      Note
      The LDA and 1D-CNN models linking diseases to herbal medicines stayed prototype experiments.
      Stack
      • SQL
      • MySQL
      • Python
