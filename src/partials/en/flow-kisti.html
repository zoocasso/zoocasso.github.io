  4. 04Processing
    • What I did
      Model 3: keyword matching of NTIS projects to NICE companies, {{f:kisti_match}} links (SQL). Model 4: price-band K-means clustering (number of clusters chosen by the Dunn index). Model 5: a daily batch that mines required-quality keywords from reviews (KeyBERT, Sentence-Transformers, Mecab). In 2024, SQL statistics on procurement prices, attributes and deliveries for model 3.1.
      Stack
      • SQL

      • Sentence-Transformers
      • Mecab
