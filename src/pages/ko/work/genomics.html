{{f:bio_ref}} 공개 레퍼런스로
유전체 변이를 주석하는 시스템

개인 유전체 변이(VCF, 칩 array)를 공개 레퍼런스와 이어 질병·형질 위험도, 집단별 빈도, 관련 의약품·한약재 정보를 주는 시스템입니다. 분석 알고리즘은 회사에서 팀장과 함께 설계했고, 파이프라인·백엔드·프런트엔드 구현과 배포는 제가 했습니다. 경희대 한의대와 캐나다 바이오 연구소가 함께한 국제 협업 과제였습니다.

적재와 주석 방법

한 번에 올릴 수 없는 크기를 나눠서 넣었습니다.

dbSNP 원본 VCF만 237 GB, 1000 Genomes 원본은 770 GB입니다. 그래서 염색체 단위로 파일을 나누고(sed, split), pandas 청크와 SQLAlchemy로 조금씩 나눠 적재했습니다.

주석은 레퍼런스 테이블을 차례로 붙이는 4단계 SQL 조인입니다. dbSNP와 1000 Genomes는 염색체·위치·REF·ALT를 이은 키로, GWAS Catalog는 rsID와 위험 대립유전자로, UniProt은 변이 ID와 대립유전자로 붙입니다. 칩 입력은 rsID로 dbSNP에서 위치 키를 찾습니다.

책임 범위

설계를 함께한 부분과 제가 구현한 부분을 나눠 적었습니다.

제가 구현·배포한 것

  • 변이 호출 파이프라인 구현 (FASTQ → BWA → samtools → Picard → GATK → VCF)
  • 고객 VCF·칩 array 입력 처리 (PyVCF)
  • 공개 레퍼런스 {{f:bio_ref}} 적재와 4단계 SQL 주석
  • GWAS 오즈비 기반 질병·형질 위험점수, 집단별 빈도, 질환별 의약품·한약재 정보
  • FastAPI JSON API와 리포트 프런트엔드(사용자 화면)
  • Docker 배포, Harbor 사설 레지스트리, 도메인·HTTPS
  • 한국과 캐나다 팀 사이의 기술 소통, 캐나다 연구소 디자이너와 요구사항 조율

함께 또는 다른 주체가 한 것

  • 팀장과 함께 · 파이프라인 알고리즘 설계
  • 캐나다 연구소 디자이너 · UI 디자인
  • 경희대 한의대 · 캐나다 바이오 연구소 · 국제 협업 과제의 파트너

배포와 한계

무엇이 운영됐고, 무엇이 실험에 그쳤는지입니다.

  1. Harbor와 Docker로 배포

    방법
    Korea IDC의 Ubuntu 운영서버에 Harbor 사설 레지스트리를 직접 구축하고(인증서, 도메인, Let's Encrypt), 이미지를 올려 Docker로 배포했습니다.
    정리
    2023년 9월 웹 화면을 떼어 내고 프런트엔드가 쓰는 JSON API로 정리했습니다.

  2. 한계

    점수
    위험도는 GWAS 오즈비·베타값을 쓰는 규칙형 점수입니다. 머신러닝 예측이 아닙니다.
    모델
    질환과 한약을 잇는 LDA와 1D-CNN 모델은 프로토타입 실험에 그쳤습니다.
    공개
    운영서버에 배포한 뒤에도 내부 IP로만 접근하게 두었습니다. 정식 서비스로 공개되지는 않았습니다.
