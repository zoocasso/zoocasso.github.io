홈/시스템/KISTI 발주 과제

공공 R&D 플랫폼의 데이터 계층을
구축·운영했습니다

KISTI가 발주하고 KISTI 연구진이 설계한 「인공지능 기반 공공 R&D 가치창출 플랫폼」(이후 SMART K2C)에서, 비전인사이드 쪽 데이터 엔지니어로 수집·적재·서빙을 전담했습니다. 쇼핑몰·조달 데이터를 모으는 수집 환경부터 분석 모델을 FastAPI 서비스와 관리 화면으로 운영화하는 일까지 맡았습니다.

기간
{{f:kisti_period}}비전인사이드 재직 · 외주 용역
역할
데이터 엔지니어수집·적재·서빙 전담
설계
KISTI 연구진일부 모델은 대학 위탁연구
결과
후속 본사업 계약으로 이어짐감리 산출물 작성 포함

아키텍처

소스에서 사용자까지 데이터가 지나가는 길입니다. 노드를 누르면 그 노드를 지나는 경로가 강조되고, 그 단계의 작업과 담당 주체가 나옵니다.

직접 구축 함께 구현 다른 주체 외부 소스·사용자
{{inc:flow-kisti}}
결과이 과제는 후속 본사업 계약으로 이어짐회사 코드는 공개할 수 없어 구조만 그렸습니다

주요 결정

데이터를 정리한 기준입니다.

  1. 상품 식별자(ASIN) 기준으로 중복 제거

    문제
    같은 상품이 여러 카테고리에 동시에 노출되어, 카테고리별로 모으면 겹쳤습니다.
    결과
    같은 ASIN을 가진 상품을 하나로 합쳐, 카테고리 사이의 중복을 없앴습니다.

책임 범위

과제 전체가 아니라, 제가 맡은 부분을 분리해 적었습니다.

제가 구축·운영한 것

  • Amazon·다나와 Selenium 크롤러, 조달청 공공데이터포털 API 수집기와 나라장터 크롤링
  • {{f:kisti_farm}}에서 돌리고 원격 DB 1대에 모으는 분산 크롤링 팜, 중복 제거
  • 중앙 MySQL 적재(조달·다나와·Amazon 데이터)
  • 직접 개발한 모델 3·4·5: 과제–기업 키워드 매칭(SQL), 가격대별 K-means(Dunn index), KeyBERT 리뷰 키워드 일일 배치. 2024년 조달청 통계 SQL
  • FastAPI 서비스와 Jinja2·Tabulator 관리 화면(필터, 순차 실행, 통합 검색, 엑셀 다운로드)
  • Amazon 수집의 Rainforest API 전환 구현 (2024년 2~5월)
  • Java Spring 기반 KISTI 프로토타입 웹에서 DB 스키마·백엔드 연동·프런트엔드 연결 담당 (사내 Java팀과 협업). 협력사 모델 1·2와 함께 사내 서버로 이전하고 Docker 실행 환경 구성
  • 감리 산출물(운영자 매뉴얼, 초기데이터구축완료보고서) 작성, 기술 회의 결과 발표와 데이터·코드 요청 대응

다른 주체가 한 것

  • KISTI 연구진 · 과제 발주와 설계
  • 대학 위탁연구팀(성균관대, 국민대) · 플랫폼 모델 일부의 알고리즘 설계
  • 협력사 · 모델 1·2
  • 사내 Java팀 · 프로토타입 웹(Java Spring) 협업 개발
  • 사내 다른 담당자 · 회의록 작성과 보고
