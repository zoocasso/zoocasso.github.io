    히타치 수탁연구 이미지 데이터 파이프라인

    규슈공업대학교 연구실의 수탁연구에서 지원연구원으로 일합니다. 유지보수할 수 없던 기존 코드를 다시 써서, 산업용 머신비전 카메라 여러 대의 제어·촬영부터 학습용 데이터셋 전처리까지 Python 파이프라인으로 만들었습니다. 비개발자 연구원이 직접 쓰도록 PyQt GUI를 만들어 PyInstaller로 배포했습니다. 후임 2명을 이끌었고, 2026년 9~10월에는 네덜란드에 출장해 현지에 시스템을 배포했습니다. 업무는 일본어와 영어로 합니다.

    연구 주제는 수탁연구 기밀이라 적지 않습니다.
