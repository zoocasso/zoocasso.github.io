Work / Genomics backend

A backend that annotates genomic variants against {{f:bio_ref}} of public reference data

I built, alone, the backend of a system that links a person's genomic variants (VCF or genotyping-array files) to public references and reports disease and trait risk, population frequencies, and related drugs and herbal medicines. It was an international collaboration between Kyung Hee University's College of Korean Medicine and a Canadian bio research lab.

  • Disease and trait risk scores from GWAS odds ratios, population frequencies, and drug and herbal-medicine lookups

Loading

The dbSNP source VCFs alone are 237 GB, and the 1000 Genomes sources are 770 GB. I split the files by chromosome (sed, split) and loaded them in pandas chunks through SQLAlchemy. Annotation joins the reference tables one after another on (chrom, pos, ref, alt), in four stages.

Deployment

I set up a Harbor private registry on an Ubuntu server at Korea IDC (certificate, domain, Let's Encrypt), pushed the images there and deployed with Docker. In September 2023 I removed the web screens and turned the service into a JSON API for the separate frontend.

Limits

  • Risk is a rule-based score from GWAS odds ratios and betas, not a machine-learning prediction.
  • The LDA and 1D-CNN models linking diseases to herbal medicines stayed prototype experiments.
  • After deployment the server was reachable only from internal IPs; it was never launched as a public service.
