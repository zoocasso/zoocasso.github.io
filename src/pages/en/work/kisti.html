Built and ran the data layer
of a public R&D platform

On the “AI-based public R&D value-creation platform” (later SMART K2C), commissioned by KISTI (Korea Institute of Science and Technology Information) and designed by KISTI researchers, I handled collection, loading and serving as the data engineer on Vision Inside's side. My part ran from the collection setup for shopping and procurement data to turning analysis models into FastAPI services and admin screens.

Key decisions

The rule used to clean the data.

  1. De-duplication by product ID (ASIN)

    Problem
    The same product appeared in several categories at once, so collecting category by category produced overlaps.
    Result
    Products with the same ASIN were merged into one, removing the overlaps between categories.

Scope

Not the whole project: the parts that were mine, listed separately.

What I built and ran

  • Selenium crawlers for Amazon and Danawa, a collector for the Public Procurement Service API on the public data portal, and crawling of the national procurement site
  • A distributed crawling farm of laptops feeding one remote database, with de-duplication
  • Loading into central MySQL (procurement, Danawa and Amazon data)
  • Models 3–5, built by me: project–company keyword matching (SQL), price-band K-means (Dunn index), a daily KeyBERT review-keyword batch. In 2024, procurement statistics in SQL
  • FastAPI services and Jinja2 and Tabulator admin screens (filters, sequential runs, unified search, Excel export)
  • Moving Amazon collection to the Rainforest API (February to May 2024)
  • Owned the DB schema, backend integration and frontend wiring of the KISTI prototype web app in Java Spring (with the in-house Java team); moved it, with a partner's models 1–2, to company servers and set up its Docker runtime
  • Audit deliverables (operator manual, initial data-build report), presenting results in technical meetings, and handling data and code requests

What others did

  • KISTI researchers · commissioning and designing the project
  • University research teams (Sungkyunkwan University, Kookmin University) · algorithm design for some of the platform's models
  • A partner company · models 1–2
  • The in-house Java team · built the Java Spring prototype web app with me
  • Another colleague · meeting minutes and reporting
